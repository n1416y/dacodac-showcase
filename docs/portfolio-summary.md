# Portfolio summary draft

I led the product direction and architecture for dacodac., a family-operations platform designed to turn scattered school and activity information into a source-aware, reviewable shared plan.

The project combines a Python/FastAPI backend, a Next.js/TypeScript interface, and a PostgreSQL-compatible model with tested workspace isolation. I used AI coding agents as implementation partners while defining requirements, security boundaries, acceptance criteria, and the distinction between prototypes and production capabilities.

The latest local checkpoint passed 1,069 backend tests with no skips, plus frontend type and production-build checks. The project is not publicly launched or production-ready: production AI is disabled, real-family enrollment is closed, and remaining container security findings block application staging.

The showcase is a curated account of the engineering journey rather than a publication of the private source repository.
